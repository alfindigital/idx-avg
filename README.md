# IDX AVG — Kalkulator Averaging Saham IDX

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![TypeScript](https://img.shields.io/badge/TypeScript-5-3178c6?logo=typescript)](https://typescriptlang.org)

Kalkulator averaging saham IDX/BEI yang cepat dan mobile-first. Hitung harga rata-rata setelah averaging up/down, tampilkan P&L, dan rencanakan strategi entry berikutnya.

---

## Fitur

- 📊 **Averaging Calculator** — Rata-rata harga beli setelah tambah lot
- 📉 **P&L Realtime** — Hitung untung/rugi berdasarkan harga saat ini
- ⌨️ **Keyboard Shortcuts** — Operasi cepat tanpa mouse
- 📱 **Mobile First** — Dioptimalkan untuk penggunaan di HP
- 🕓 **Riwayat** — Simpan kalkulasi sebelumnya
- 📲 **PWA** — Installable

---

## Quick Start

```bash
git clone https://github.com/alfindigital/idx-avg.git
cd idx-avg
npm install
npm run dev
npm run build
```

---

## Stack

- TanStack Start + TypeScript 5
- Tailwind CSS + shadcn/ui
- PWA ready

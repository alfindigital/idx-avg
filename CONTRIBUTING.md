# Panduan Kontribusi

## Cara berkontribusi

1. **Fork** repo ini
2. Buat branch: `feat/fitur`, `fix/bug`, `docs/perubahan`
3. Commit: `feat: deskripsi`, `fix: deskripsi`
4. Buka Pull Request

## Dev

```bash
npm install
npm run dev
npm test
npm run build
```

## Jangan commit

- File `.env*` (kecuali `.env.example`)
- API key, credential, atau token
- Folder `.agents/`, `.lovable/`

## Lisensi

Kontribusimu dilisensikan di bawah [MIT](LICENSE).
